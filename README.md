# Understanding Speaker Verification

This repository contains a small set of experimental notebooks focused on speaker verification using different deep learning approaches.

## Overview

The work here explores speaker embedding and verification pipelines with several model architectures, including:

- DELULU-based experimentation
- ECAPA-TDNN
- ReDimNet2

Each notebook is intended as a personal research and experimentation space for testing model behavior, evaluation strategies, and implementation ideas.

## Project structure

- `Speaker_Verification_with_DELULU.ipynb` — experiments using the DELULU approach
- `Speaker_Verification_with_ECAPA_TDNN.ipynb` — ECAPA-TDNN speaker verification experiments
- `Speaker_Verification_with_ReDimNet2.ipynb` — experiments using ReDimNet2

## Notes

This is an exploratory project rather than a production-ready package. The notebooks are meant for learning, prototyping, and iterative experimentation.

## Suggested workflow

1. Open the notebook of interest.
2. Review the dataset and preprocessing steps.
3. Run the training/evaluation pipeline.
4. Compare results across different model variants.
